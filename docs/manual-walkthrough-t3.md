# T3 walkthrough

This extends the existing T1/T2 loop. The new GUI and rendered textures still need an owner playtest. Recipes and costs are editable JSON; see [the generated balance table](t3-slice.md) and [crafting recipes](recipes.md).

1. Craft a Boule Purifier controller, an E-beam Mask Writer controller, support casings, support power ports, and **optionally support water inlets**. New support-machine and T3 upgrade recipes consume T2 logic chips. Build each support machine **2 wide, 2 high and 3 deep**. Place its controller in either lower front column; use one or two support power ports and fill the other positions with support casings **or support water inlets (purifier only)**. These two machines do not use the lithography machine's upper Operating Panel. The existing joined fab panels are reused.
2. Supply FE through a formed support power port. The purifier starts with an empty 16,000 mB tank. **Insert water via buckets on any inlet/controller GUI, or pipe water into any support water inlet (all faces, insert-only, water-only, ArcForge/NeoForge conduits).** Insert an ordinary silicon boule; retrieve the empty bucket if using buckets. Each bucket adds 1,000 mB only when the full amount and returned bucket fit. Default purification takes 400 ticks and 32,000 FE, consuming one ordinary boule and 1,000 mB water for one pure silicon boule. A full output or missing power pauses work. Water pipes are now available through the optional Support Water Inlet; item automation is deferred.
3. Slice the pure boule in the existing Wafer Slicer using an empty FOUP. The boule determines the new lot's substrate. Inspect the FOUP tooltip for pure wafer type, wafer count and layer progress. The tooltip must not reveal hidden rolls or lot identity. Ordinary wafers remain useful for T1/T2; pure wafers also support those tiers.
4. In the E-beam Mask Writer, select a design with the arrows. Supported designs are logic T1/T2/T3, memory T2/T3, compute T3 and NAND T3. Insert a blank mask and redstone, then press **Write mask**. The default cost per design is one blank mask, 32 redstone and 2,400,000 FE over 1,200 ticks. Supply power throughout the job or fill the 4,000,000 FE buffer beforehand. Changing the selected design while idle changes the displayed costs. An active job preserves its accepted design, costs and mask-use count across reloads. Retrieve one generation-2 mask; writing does not repeat automatically.
5. Upgrade the lithography machine's five permanent line components to the KrF Excimer Laser, DUV Projection Lens, Precision Stepper Stage, HEPA Filter and Laser Interferometer. Supply T3 resist, the matching T3 E-beam mask, a pure wafer FOUP and FE through the existing formed machine. Use its upper Operating Panel as before. T3 uses 24 layers, with 100 ticks per layer before applicable existing timing rules. Ordinary wafers and generation-1 Pattern Generator masks cannot start T3. Confirm a refused start consumes no resist, mask uses or power.
6. Run each of the four T3 designs and process the completed lot in Test and Package with its normal packaging supplies. Expect the matching T3 logic, memory, compute or NAND chips according to yield; the returned FOUP is empty. T3 compute has one fixed core. Core-count choices still begin at T6; no T4 content is added here.
7. Check pause/resume by removing power during purification, mask writing and lithography, then restoring it. Also check blocked outputs, save/reload during work, and one-time ingredient consumption. Existing T1/T2 machines and ordinary wafer recipes should continue to work.

The Crystal Puller and Wafer Slicer output slots have moved away from the player inventory. Confirm both screens visually at your normal GUI scale.

To refine starter sprites, edit `tools/starter-textures.json`, then run `node tools/generate-starter-textures.mjs` and `node tools/generate-joined-panels.mjs`. Use each script's `--check` mode to check generated assets without writing. Support blocks reuse the existing joined models; edit those shared textures when changing the shared panel style.

## Optional pipe-fed water

See [Purifier water inlet](purifier-water-inlet.md) for casing replacement, crafting and Arcforge conduit setup. Bucket input remains in the purifier GUI. Water pipes are now authorized; item automation and T4 remain deferred.
