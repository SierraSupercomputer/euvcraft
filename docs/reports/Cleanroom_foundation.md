# T5 cleanroom foundation

Scope: optional cuboid cleanrooms for T5 scanner wafer yield, with persistent loaded-time filtration, reduced gown pollution and sealed utility transport. FOUP cleaner and all T6/T7 consequences remain deferred.

Nine new blocks, filter medium and a four-piece gown are registered in the normal creative tab. Four passive shell blocks intentionally have no block entity; controller/filter/ports have explicit audited native capabilities. Ports forward in all six axis directions through the actual transactional FE/fluid/item framework and expose no transverse or wrong-role handler. Filter medium has a typed transactional slot. No replacement transfer API is introduced.

Atmosphere is pure Java with editable JSON rules. New controllers start dirty; media wear, FE, cleanliness and last valid bounds persist. Scans are bounded, cached and loaded-only; no world/chunk reads occur during setRemoved. Unavailable known room chunks pause simulation/associated scanner processing. The weak loaded-room index retains only positions and immutable geometry; it cannot discover never-loaded controllers across a restart. Standalone cuboids are the supported first increment; shared shells and arbitrary shapes are not supported.

A T5 scanner samples only successfully paid processing ticks, storing accumulated exposure in its FOUP. The final mean room factor multiplies frozen equipment yield once, reweighting the original latent roll product without random draws. Saved completion markers prevent repeated application. Packaging and assembly receive no additional room charge; T1–T4 processing is unchanged. Private exposure and rolls remain absent from the public stream codec.

The controller/filter screens use a compact opaque panel and full32-bit values split across native16-bit data slots, including FE, signed trend and distant fault coordinates. Recipes, textures and gown equipment layers are generated reproducibly by generate-cleanroom-assets.mjs and remain editable.

Verification uses the complete unit/core-boundary/jar checks; all previous273 project native IDs plus13 new cases; real-room formation/breach/door/controller/media/gown/persistence/unavailable-footprint cases; six-axis FE/item transfers, fluid transactions, bounded/stale port handlers; and a pristine-to-breached T5 scanner run expecting a75% room factor. No existing world conversion is required. Historical completed T5 lots are not retroactively penalized; historical partial lots begin accumulating exposure on subsequent processing ticks. See the cleanroom walkthrough for bounds, defaults, limitations and testing steps.
