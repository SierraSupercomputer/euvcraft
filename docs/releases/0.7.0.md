# EUVCRAFT 0.7.0 — Alpha

Tier 7 introduces split EUV lithography and a larger fab infrastructure challenge.

## Changes

- Separate 5×5×7 EUV scanner and 3×3×5 light source connected by an enclosed beamline, with consumable tin feedstock.
- Fab Hydrogen purification and pressurized distribution, dedicated vacuum pumps and an optional shared central vacuum plant.
- Larger G3 deposition/etch preparation with an ultrapure-water rinse, and a new reticle writer whose cleanroom conditions affect mask durability.
- Required T7 cleanroom enclosure, contaminated FOUPs and persistent equipment contamination after containment breaches, with repair and scanner recalibration.
- T7 compute, memory and NAND chips, CPU/DIMM reflow recipes and T6-to-T7 compute high binning.
- Editable JSON costs/recipes, new block art, controller tooltips and a complete T7 walkthrough. Corrected the walkthrough's reticle-writer requirement to 8,000 FE/t.

## Installation

Use Java 25, Minecraft 26.3 and NeoForge 26.3.0.69-beta (tested). Install lithmod-0.7.0.jar with Arcforge 2.8.1+26.3 and Encoded Logistics 1.5.0+26.3 on client and server. Replace the previous EUVCRAFT JAR.

Do not install arcforge-api-1.2.0+26.3.jar; it is a compile-only developer artifact.

## Verification and limitations

The integrated T7 gameplay build passed 1,402 unit tests, 347 project in-game checks, a fixture-disabled shipping check and eight generator/resource checks. Release packaging repeats unit/core/shipping checks and verifies every packaged class/resource against that tested build, allowing only the embedded version change.

This is an Alpha prerelease. The T7 manual client walkthrough and balance assessment remain pending. Existing lower-tier content is retained; T7 requires its new machines and utilities. Back up worlds before updating. Reflow balance refinements, scrap recycling, T8 and Encoded Logistics hardware integration remain deferred.
