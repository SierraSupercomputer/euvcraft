# EUVCRAFT 0.9.0 — Alpha

## Changes since 0.8.0

- Added Tier 8 fabrication with a Chemical Mechanical Planarizer, High-NA EUV Scanner and Ion Implanter. T8 uses the existing EUV light source and utility network, with new reticles, process consumables and family-specific modules.
- Added planarizer calibration. Adjust platen speed and pressure and spend one wafer from a separate sample FOUP per test polish.
- Specialized T7 and T8 etching for compute and memory. Configure and tune the appropriate module for the lot. NAND uses the standard etch configuration.
- Moved high binning to a dedicated High-Bin Test & Package. Completed T8 compute lots can attempt the God Chip challenge for a trophy and advancement.
- Added a cleanroom Filters tab with absolute coordinates, fault-first sorting, and filter power and medium status.
- Added all 24 bundled photomask and reticle designs to JEI search. Hover over an entry for its chip family and tier, then press **R** for its writer or **U** for its exposure step.
- Added an optional Tier 1 quest pilot for Hibiscus Quests.

## Install and upgrade

Use Java 25, Minecraft 26.3 and NeoForge 26.3.0.99. Install `lithmod-0.9.0.jar` with Arcforge 2.8.1+26.3 and Encoded Logistics 1.5.0+26.3 on both client and server. JEI 31.14.0.72 and its matching MezzConfig dependency are optional on the client.

Back up worlds and finish active lots before upgrading. Check the etch module and tuning before processing new T7 compute or memory lots. If an older processed FOUP lacks the required route data, start with a fresh lot or empty it in the FOUP Cleaner. See the [T1–T8 progression guide](../playtest-progression.md) for construction, calibration and routing.

For the Zone Refiner, use the Pure Silicon Boule from the Boule Purifier in the upper panel’s left input slot. The Zone Refiner uses ultrapure water.
