# EUVCRAFT 0.6.0 — Alpha

Pre-1.0 development release for Minecraft26.3. This release advances the previous Alpha0.5.1 feature line; the earlier internal1.0.0 build placeholder has been replaced with the actual release version.

## Changes

- Tier6 progression: electronic-grade zone refining, scanner multi-patterning, selectable compute cores and calibrated reflow assembly with assembly scrap.
- Cleanroom power, fluid and item-port bridge repairs, improved machine diagnostics/progress, calibration reset behavior and interface fixes.
- Creative inventory handling preserves full FOUP lot state and frozen outcomes during moves/clones without rerolling. Survival synchronization remains public-only.
- Updated runtime dependencies to Arcforge2.8.1+26.3 and Encoded Logistics1.5.0+26.3.

## Installation

Use Java25 and Minecraft26.3 with NeoForge26.3.0.69-beta (tested). Install lithmod-0.6.0.jar alongside Arcforge2.8.1+26.3 and Encoded Logistics1.5.0+26.3 on the client and server. Remove older copies of these mods.

**Do not install arcforge-api-1.2.0+26.3.jar.** It is a compile-only developer artifact; the full Arcforge mod supplies the API at runtime.

## Verification and limitations

The current gameplay build passed1295unit tests,326project native cases, fixture-disabled shipping and6generator checks before release versioning. Release packaging verifies unchanged gameplay classes/resources, the embedded0.6.0 version, unit tests and the fixture-disabled shipping probe.

This remains an Alpha build. Client-side playtesting of the dependency update is pending. Previously damaged processed FOUP summaries cannot recover lost private results; recreate those lots. Reflow-control balance refinements and the future scrap recycler remain deferred.

See docs/playtest-progression.md for progression and docs/manual-walkthrough-creative-foup.md for the focused Creative FOUP check.
