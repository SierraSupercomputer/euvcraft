# EUVCRAFT 0.8.0 — Alpha

## Changes since 0.7.1

- Add a powered single-block Scrap Recycler: 64 Wafer Scrap, Chip Scrap or Assembly Scrap become one Silicon in 400 ticks at 40 FE/t. Each recipe is editable JSON; no water is required. All-face Arcforge item automation accepts recipe inputs and extracts finished output.
- Consolidate construction, progression and walkthroughs into one [T1–T7 guide](../playtest-progression.md), with an [issue index](../issues/README.md) separating open reports from implemented repairs.
- Add optional JEI process lookup with controller crafting stations, server-loaded recipe costs and item/fluid/gas lookup.
- Make later fabrication linear: T4 deposition → scanner → etch → packaging; T5+ adds coating and productive wet cleaning, while T7 uses separate G3 deposition/etch chambers. Shared costs and yield factors apply once.
- Add public FOUP route/next-step hints and separate Resources, Fab Blocks and Items creative tabs.
- Add optional transactional fab item ports for the later lines.
- Join cleanroom wall textures while keeping floors tiled; use the supplied Blockbench beamline model with axis-aware placement.

## Install and upgrade

Use Java 25, Minecraft 26.3 and NeoForge 26.3.0.99. Install lithmod-0.8.0.jar with Arcforge 2.8.1+26.3 and Encoded Logistics 1.5.0+26.3 on client and server. Do not install the compile-only Arcforge API JAR. JEI is optional; its own dependencies must be installed if used.

Back up worlds and finish active lots before upgrading. T4+ production now requires the new route stages. Older processed FOUPs may lack paid-stage evidence and cannot skip the new stages; use fresh lots or discard them with the FOUP Cleaner. The recycler itself is additive and needs no world conversion. Keep matching client/server versions. Existing machine geometry and operating-panel placement are retained.

## Balance and limitations

The default recovery ratios are deliberately lossy even across multiple lots. Recheck material loops when changing wafer counts, chip yields, scrap outputs or recovery recipes. The recycler accepts loose recipe ingredients, not live wafers, FOUPs, chips or masks. Existing FOUP cleaning remains the disposal step.

Reflow dwell/cooling clarity remains an unreproduced report; no reflow mechanics changed. T8, NAND assembly, Ponder and Encoded Logistics hardware/server progression are not included. This is an Alpha prerelease.
